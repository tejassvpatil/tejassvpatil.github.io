Research

Multimodal learning for cognitive health

Models that combine neuroimaging, longitudinal cognition, genetics, and passive sensing. A tri-modal model for stable versus progressive mild cognitive impairment reached a ROC-AUC of 0.918.

3D CNN · GRU · cross-modal attention · ADNI

code ↗

Remote care and in-home sensing

Sensor-derived activity summaries, privacy boundaries, and caregiver–patient workflows for I-Care. The system work includes real-time communication, calendars, authorization, and research data infrastructure.

Firebase · FastAPI · Python · React · Vue

Foundation models for care systems

Activity-centric timeline descriptions, constrained delegation for conversational agents, and evaluation of multimedia communication designed for cognitive accessibility.

LLMs · multimodal models · HCI · evaluation

Additional work

Promptable instance segmentation with diffusion models, transformer-based failure prediction in HPC logs, glucose forecasting, and empirical analysis of software ecosystems.

PyTorch · transformers · computer vision · applied ML
